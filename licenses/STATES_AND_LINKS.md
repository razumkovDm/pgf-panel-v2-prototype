# Карта маршрутов и матрица состояний «Моих лицензий» (`#614`)

## 1. Маршруты и переходы

| Элемент / действие | Канонический маршрут в Panel V2 | Поведение в HTML-макете | Условие |
|---|---|---|---|
| Вход после оплаты из `#609` («Перейти в Мои лицензии») | `/app/licenses` | Открытие `index.html` (Список лицензий) | Авторизованный `USER` |
| Прямой вход в карточку по URL | `/app/licenses/[id]` | `index.html?id=LIC-A1B2C3D4E5F6` | Известный `Public ID` пользователя |
| Неизвестный / malformed `?id=` | `/app/licenses/[id]` → `404` / возврат | Красный алерт `role="alert"` с безопасным выводом `id` через `textContent` и кнопкой «Вернуться к «Моим лицензиям»» | Несуществующий или некорректный ID (защита от DOM-XSS) |
| Кнопка «+ Купить лицензию» / «Выбрать тариф» | `/app/billing/checkout` (или `/?cfg=…#pricing`) | Ссылка `../checkout/index.html?cfg=30d-2pc-seo1` | Всегда доступна |
| Кнопка «Пробный период» | `/app/trial` | Информационное окно предпросмотра маршрута | Если триал доступен пользователю |
| Кнопка «Перенести от реселлера» | `/app/licenses/transfer` | Информационное окно предпросмотра маршрута | Подтверждение права отдельно от ключа (§6.2 `#590`) |
| Кнопка «Устройства →» / плитка «Устройства этой лицензии (2 / 3) →» | `/app/licenses/[id]/devices` | Предпросмотр маршрута (отдельный следующий макет — Макет 4) | Для всех статусов, кроме `REVOKED` |
| Кнопка «Продлить» | `/app/billing/checkout?cfg=…&renew=[id]` | Предпросмотр перехода с сохранением `cfg` и пометкой изменения устройств/SEO со следующего периода | Недоступно для `REVOKED` |
| Плитка «Докупить устройства / SEO» | `/app/billing/checkout?upgrade=[id]` | Предпросмотр пропорциональной докупки | Только для `ACTIVE` |
| «Скачать Scenor» / «Как активировать» / «Написать в поддержку» | `/app/downloads`, `/docs/activation`, `/app/support` | Предпросмотр маршрутов; в поддержке напоминается передавать только `Public ID` | Всегда доступны |
| «Документация», «Wiki и ошибки», «Поиск помощи Ctrl+K» | `/docs`, `/wiki` | Модальный быстрый поиск по статьям справки | Открыты всегда без авторизации |

## 2. Матрица состояний списка `/app/licenses` (K1, §3.5 `#590`)

| Состояние | Отображение | Доступные действия | Инвариант |
|---|---|---|---|
| **`filled` (Заполненный)** | Карточки 4 статусов (`ACTIVE`, `TRIAL`, `EXPIRED`, `REVOKED`), счётчик `(4)`, фильтр по статусу и поиск по названию / `Public ID` | Копирование ключа (на `ACTIVE`/`TRIAL`), `Продлить` (на `EXPIRED`), `Устройства →`, `Открыть →` | Нет горизонтального переполнения на 1440 и 390 px |
| **`loading` (Загрузка)** | 3 скелетон-карточки (`aria-busy="true"`, `role="status"`) | — | Никогда не показывает ложное «У вас пока нет лицензий» |
| **`empty` (Пусто)** | Карточка «У вас пока нет лицензий» | `Выбрать тариф`, `Пробный период`, `Перенести от реселлера` | Чёткий путь к первой лицензии |
| **`error` (Ошибка загрузки)** | Баннер/карточка `role="alert"` «Не удалось загрузить лицензии» | `Повторить` (возвращает через `loading` к `filled`), `Wiki и ошибки` | Ошибка не маскируется под пустое состояние |
| **Пустой результат фильтра/поиска** | Карточка «Ничего не найдено» с текстом запроса через `textContent` | `Сбросить фильтры` | Безопасный рендер произвольного ввода без DOM-XSS |

## 3. Матрица состояний карточки `/app/licenses/[id]` и операций с ключом (K2, ТЗ 70 / §4.3)

| Сценарий | Поведение в макете | Ожидаемый результат |
|---|---|---|
| Редактирование названия | Inline-форма `Ред. название` → `Сохранить` / `Отмена` | Валидация непустого значения, вывод строго через `textContent`, обновление в карточке и в списке |
| Редактирование личного примечания | Inline-форма `Изменить` → `Сохранить примечание` / `Отмена` | Вывод строго через `textContent`, допускает очистку (`Не задано`) |
| Разделение Среза 3 и Среза 4 | Переключатель `Срез 4` / `Срез 3` в верхней панели | В Срезе 4 видны баланс в шапке, `Баланс и счета`, `Рефералы`, отметка и переключатель автопродления; в Срезе 3 баланс и автопродление полностью скрыты |
| Копирование ключа (Clipboard API доступен) | Кнопка «Копировать ключ» | Вызов `navigator.clipboard.writeText`, тост «Ключ скопирован» |
| Копирование ключа (fallback без Clipboard API) | Тумблер «Fallback буфера» или недоступный `navigator.clipboard` | Фокус и выделение поля ключа + явный жёлтый баннер «Автоматическое копирование недоступно — нажмите Ctrl+C» + тост |
| Замена ключа (штатная) | Модалка подтверждения (`expectedRotationCounter`, `idempotencyKey`), защита от двойного клика | Новый ключ `PGF-…` на месте, ревизия `+1`, срок и устройства `2 / 3` сохранены, зелёный баннер подтверждения |
| Замена ключа (`409 REVISION_CONFLICT`) | Тумблер `409 конфликт` в панели или модалке | Красный баннер `409 REVISION_CONFLICT`, автоматическое обновление карточки до актуального ключа и ревизии сервера |
| Отозванная лицензия (`REVOKED`) | Карточка `LIC-R4V6K8D2N9Q1` | Красный баннер пояснения; кнопки копирования/замены ключа отключены (`disabled`); ложных кнопок активации/продления нет |
